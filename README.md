## 🖥️ Running the Project on Windows

### Prerequisites
- Python installed on your system.
- Git (optional).
- Required AI API credentials, if using live AI services.

### Installation and Execution

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal in the project directory.
4. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

5. Activate the virtual environment:

   ```bash
   venv\Scripts\activate
   ```

6. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

7. Configure your API credentials using the environment variables described in `.env.example`. Do not upload your actual `.env` file or API keys.

8. Run the application:

   ```bash
   python run.py
   ```

9. Open the local URL displayed in your terminal in your browser.

*Note: Follow the actual entry point, environment configuration, and startup instructions in your project code if they differ from these commands.*
